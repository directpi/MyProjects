# Чеклист безопасности для тестирования системы управления автопарком

**Версия документа:** 1.0  
**Дата создания:** 2025-10-30  
**Автор:** Directpi  
**Статус:** Активен

**Основа:** OWASP Top 10, стандарты безопасности API

## 1. Аутентификация и авторизация

### 1.1 Аутентификация

- [ ] ✅ Логин с валидными учетными данными работает корректно
- [ ] ✅ Логин с невалидными учетными данными отклоняется (401/403)
- [ ] ✅ Логин с пустыми полями отклоняется
- [ ] ✅ Логин с SQL injection не выполняется
- [ ] ✅ Логин с XSS payload не выполняется
- [ ] ⚠️ Логин с длинными строками (DoS атака) - требуется проверка
- [ ] ✅ Токены имеют ограниченное время жизни
- [ ] ✅ Refresh токены работают корректно
- [ ] ✅ Refresh токены недействительны после истечения срока

### 1.2 Авторизация

- [ ] ✅ Неавторизованные запросы блокируются (401/403)
- [ ] ✅ Авторизованные запросы с валидным токеном проходят
- [ ] ✅ Запросы с истекшим токеном отклоняются
- [ ] ✅ Запросы с невалидным токеном отклоняются
- [ ] ✅ Запросы с токеном другого пользователя отклоняются (где применимо)
- [ ] ⚠️ Проверка прав доступа (RBAC) - требуется расширенное тестирование
- [ ] ⚠️ Проверка владения ресурсами (ownership) - частично протестировано

## 2. Валидация входных данных

### 2.1 Общие проверки

- [ ] ⚠️ Email валидация - обнаружены проблемы (BUG-USER-EMAIL-VALIDATION)
- [ ] ⚠️ Phone валидация - обнаружены проблемы (BUG-USER-PHONE-VALIDATION)
- [ ] ✅ Обязательные поля проверяются
- [ ] ⚠️ Проверка длины полей - частично протестировано
- [ ] ⚠️ Проверка типов данных - требуется расширенное тестирование
- [ ] ⚠️ Проверка специальных символов - требуется тестирование

### 2.2 SQL Injection

- [ ] ⚠️ Проверка SQL injection в параметрах запросов - требуется тестирование
- [ ] ⚠️ Проверка SQL injection в телах запросов - требуется тестирование
- [ ] ⚠️ Проверка SQL injection в заголовках - требуется тестирование

**Тестовые примеры:**
```
' OR '1'='1
'; DROP TABLE users; --
UNION SELECT * FROM users
```

### 2.3 XSS (Cross-Site Scripting)

- [ ] ⚠️ Проверка XSS в параметрах запросов - требуется тестирование
- [ ] ⚠️ Проверка XSS в телах запросов - требуется тестирование
- [ ] ⚠️ Проверка XSS в ответах API - требуется тестирование

**Тестовые примеры:**
```
<script>alert('XSS')</script>
<img src=x onerror=alert('XSS')>
javascript:alert('XSS')
```

### 2.4 Command Injection

- [ ] ⚠️ Проверка command injection - требуется тестирование
- [ ] ⚠️ Проверка path traversal - требуется тестирование

**Тестовые примеры:**
```
; ls
| cat /etc/passwd
../etc/passwd
```

### 2.5 Граничные значения

- [ ] ✅ Максимальная длина полей проверяется
- [ ] ✅ Отрицательные значения отклоняются (где применимо)
- [ ] ⚠️ Очень большие числа - требуется проверка
- [ ] ⚠️ Пустые строки vs NULL - требуется проверка

## 3. Управление сессиями

### 3.1 Токены

- [ ] ✅ Access токены имеют ограниченное время жизни
- [ ] ✅ Refresh токены имеют ограниченное время жизни
- [ ] ✅ Токены уникальны для каждого пользователя
- [ ] ⚠️ Проверка токенов на повторное использование - требуется проверка
- [ ] ⚠️ Проверка отзыва токенов - требуется проверка

### 3.2 Безопасность хранения

- [ ] ⚠️ Токены не логируются в открытом виде - требуется проверка
- [ ] ⚠️ Пароли не возвращаются в ответах - требуется проверка
- [ ] ⚠️ Пароли не логируются - требуется проверка

## 4. Защита от CSRF (Cross-Site Request Forgery)

- [ ] ⚠️ Проверка Origin/Referer заголовков - требуется проверка
- [ ] ⚠️ SameSite cookies (если применимо) - требуется проверка

## 5. Защита от DoS (Denial of Service)

### 5.1 Rate Limiting

- [ ] ⚠️ Rate limiting настроен для register - требуется проверка
- [ ] ⚠️ Rate limiting настроен для других эндпоинтов - требуется проверка
- [ ] ⚠️ Блокировка после превышения лимита - требуется проверка

### 5.2 Resource Exhaustion

- [ ] ⚠️ Защита от больших payload - требуется проверка
- [ ] ⚠️ Защита от большого количества запросов - требуется проверка
- [ ] ⚠️ Таймауты для долгих операций - требуется проверка

- [ ] ⚠️ Чувствительные данные шифруются - требуется проверка
- [ ] ⚠️ Пароли хешируются (не в открытом виде) - требуется проверка

### 6.2 Логирование

- [ ] ⚠️ Чувствительные данные не логируются - требуется проверка
