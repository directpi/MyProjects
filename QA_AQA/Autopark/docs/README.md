# Документация по тестированию системы управления автопарком

**Версия:** 1.0  
**Дата обновления:** 2025-10-30

---

## Навигация по документам

### Основные документы

#### 1. [Обзор проекта](./project.md)
Общее описание проекта, тестовая стратегия, архитектура тестового стенда, текущий статус QA и известные баги.

#### 2. [План тестирования](./test_plan.md) ⭐
Полный план тестирования системы, включая подход, расписание, ресурсы, критерии входа/выхода, метрики.

#### 3. [Тестовая стратегия](./test_strategy.md) ⭐
Детальная стратегия тестирования: типы тестов, уровни тестирования, подходы, инструменты, best practices.

---

### Тестовые артефакты

#### 4. [Тест-кейсы](./test_cases.md)
Детальная таблица всех тест-кейсов с описанием, шагами, ожидаемыми результатами и статусами.

#### 5. [Сводка API эндпоинтов](./api_endpoints_summary.md)
Полный список всех API эндпоинтов системы, их статус тестирования и приоритеты.

#### 6. [Матрица трассируемости](./traceability_matrix.md)
Связь между требованиями (эндпоинтами) и тест-кейсами, покрытие по модулям, gaps в покрытии.

---

### Отчетность

#### 7. [Шаблон баг-репорта](./bug_report_template.md)
Форма для оформления багов с примерами, классификацией приоритетов и процессом работы.

#### 8. [Реальные баг-репорты](./bug_reports.md) ⭐
Реальные баг-репорты по найденным проблемам (BUG-USER-EMAIL-VALIDATION, BUG-USER-PHONE-VALIDATION).

#### 9. [Шаблон отчета о тестировании](./test_report_template.md)
Шаблон финального отчета о тестировании с метриками, статистикой, выводами и рекомендациями.

#### 10. [Отчет о тестировании (30.10.2025)](./test_report_2025-10-30.md) ⭐
Реальный отчет о результатах тестирования за период 20-30 октября 2025 года.

---

### Аналитика и риски

#### 11. [Анализ рисков](./risk_analysis.md)
Детальный анализ рисков тестирования, матрица рисков, планы митигации, мониторинг.

#### 12. [Чеклист безопасности](./security_checklist.md)
Чеклист для security тестирования на основе OWASP Top 10, проверка всех аспектов безопасности.

---

### Дополнительные планы

#### 13. [План производительного тестирования](./performance_test_plan.md) 📋
План нагрузочного и производительного тестирования (ожидает реализации).

## Быстрый старт

### Для новых членов QA команды:
1. Начните с [Обзора проекта](./project.md) - понимание системы
2. Изучите [План тестирования](./test_plan.md) - что и как тестируем
3. Прочитайте [Тестовую стратегию](./test_strategy.md) - подходы и методы
4. Ознакомьтесь с [Тест-кейсами](./test_cases.md) - что уже покрыто

### Для разработчиков:
1. [Сводка API эндпоинтов](./api_endpoints_summary.md) - что тестируется
2. [Шаблон баг-репорта](./bug_report_template.md) - как оформить найденные проблемы
3. [Матрица трассируемости](./traceability_matrix.md) - покрытие требований

### Для менеджеров:
1. [План тестирования](./test_plan.md) - расписание и ресурсы
2. [Шаблон отчета о тестировании](./test_report_template.md) - метрики и статус
3. [Анализ рисков](./risk_analysis.md) - потенциальные проблемы
