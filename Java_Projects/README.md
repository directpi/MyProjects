### В данном разделе представлены учебные проекты на языке Java.

[1. RogueLike](./RogueLike/README.md)  
*Консольное игровое «rogue-like» приложение на языке программирования Java с использованием библиотеки curses (в версии JCurses для Java) в духе классической игры Rogue 1980 года разработки*

[2. Tic-Tac-Toe (базовая версия) + Тесты](./Tic_Tac_Toe/README.md)  
*Веб-приложение на языке Java с использованием Spring, базовой auth-авторизацией*

[3. Tic-Tac-Toe (JWT версия) + Тесты](./JWT_TicTacToe/README.md)  
*Веб-приложение на языке **Java** с использованием Spring, c jwt-авторизацией, игрой с ИИ (алгоритм MiniMax), поддержкой истории игр, таблицей лидеров*

[4. BrickGame v3.0 Racing + Тесты](./BrickGame_v3.0_Racing_Snake_Tetris/README.md)  
*Реализация классических игр "Speed Race" (1974, Taito), Snake, Tetris с современной архитектурой. Проект представляет собой многоплатформенную игру с тремя интерфейсами (Web, Desktop, CLI), использующую REST API для взаимодействия клиента и сервера.*

[5. RESTful HTTP API Магазин бытовой техники](./RESTfull_API_MyShop/README.md)  
*Решение представляет собой сервис с RESTful HTTP API, описанным в соответствии со спецификацией OpenAPI, реализованным с подключением к БД и снабжённым интерактивной документацией через Swagger UI.*
