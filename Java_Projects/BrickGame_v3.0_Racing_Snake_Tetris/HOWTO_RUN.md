# 🎮 BrickGame v3.0 - Инструкции по запуску

## 📋 Предварительные требования
- Java 21 (JDK)
- Gradle (встроен в проект через wrapper)

---

## 🚀 Запуск проекта

### 1️⃣ **Запуск REST API сервера**

Откройте **первый терминал** и выполните:

```bash
cd /home/directpi/21school/AP2_BrickGame_v3.0_Java.ID_1449918-1
./gradlew bootRun
```

**Ожидайте сообщение:**
```
Started BrickGameApplication in X.XXX seconds
```

**Сервер будет доступен по адресу:** `http://localhost:8080`

**API endpoints:**
- `GET  /api/games` - список игр
- `POST /api/games/{gameId}` - запуск игры (gameId=1 для Racing)
- `POST /api/actions` - отправка действий
- `GET  /api/state` - получение состояния игры
- `GET  /swagger-ui.html` - документация API

---

### 2️⃣ **Запуск Swing GUI клиента (Desktop)**

Откройте **второй терминал** и выполните:

```bash
cd /home/directpi/21school/AP2_BrickGame_v3.0_Java.ID_1449918-1
./gradlew runSwing
```

**Откроется окно с игрой Racing**

**Управление:**
- **Стрелки ←/→** - смена полосы
- **Стрелка ↑** - ускорение
- **Space** - старт/рестарт игры
- **P** - пауза
- **Esc** - выход

---

### 3️⃣ **Запуск Web GUI клиента (Браузер)**

**Сервер должен быть запущен!**

Откройте браузер и перейдите по адресу:
```
http://localhost:8080/
```

**Управление:**
- **Кнопка "Start Game"** или **Space** - запуск игры
- **Стрелки ←/→** - смена полосы
- **Стрелка ↑** - ускорение (удерживать)
- **P** - пауза
- **Esc** - выход

## 🎯 Игровая механика Racing

- **Цель:** набрать максимальное количество очков, избегая столкновений
- **Очки:** +1 балл за каждую проезженную машину соперника
- **Уровни:** каждые 5 очков = +1 уровень (макс 10)
- **Скорость:** увеличивается с уровнем + ручное ускорение стрелкой ↑
- **Столкновение:** завершает игру
- **High Score:** сохраняется между запусками

## 🐛 Решение проблем

### Порт 8080 занят
```bash
# Найти процесс на порту 8080
lsof -i :8080

# Убить процесс
kill -9 <PID>
```

### Ошибка "NO_GAME_RUNNING"
Это нормально, если игра еще не запущена. Web GUI будет показывать эти ошибки до нажатия "Start Game".

### Gradle Daemon проблемы
```bash
./gradlew --stop
```

### Swing окно не открывается
Убедитесь, что у вас настроен X11 forwarding (для WSL) или DISPLAY переменная установлена.
