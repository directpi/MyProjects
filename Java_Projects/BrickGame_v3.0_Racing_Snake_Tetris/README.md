# BrickGame v3.0 Racing

BrickGame v3.0 Racing — это коллекция классических аркадных игр с современной архитектурой. Проект включает три игры: **Racing** (реализация "Speed Race", 1974, Taito), **Snake** (классическая змейка) и **Tetris** (культовая головоломка). Проект представляет собой многоплатформенную систему с тремя интерфейсами (Web, Desktop, CLI), использующую REST API для взаимодействия клиента и сервера.

## Общая информация

### Описание проекта

Проект включает в себя:

- **Серверную часть** на Java с REST API
- **Игровую логику** на основе конечного автомата (FSM)
- **Три клиентских интерфейса**: Web (HTML/JavaScript), Desktop (Qt/Swing), CLI (ncurses)
- **Поддержку игр** из предыдущих версий BrickGame (Tetris, Snake)
- **Универсальную клиентскую библиотеку** для взаимодействия с REST API

**Racing** — гоночная игра, где игрок управляет автомобилем на трехполосной дороге, избегая столкновений с машинами соперников.

- **Поле игры**: 10×20 клеток (логическая сетка)
- **Управление**: 
  - Стрелки ←/→ — смена полосы
  - Стрелка ↑ — ускорение (удерживать)
  - Space — старт/рестарт игры
  - P — пауза
  - Esc — выход
- **Система очков**: начисление очков за проезд машин соперников
- **Система уровней**: каждые 10 очков = +1 уровень (максимум 10)
- **Лучший результат (High Score)**: рекордный счет сохраняется в файл `data/highscore.json` (формат JSON). При достижении нового рекорда файл автоматически обновляется, а при следующем запуске приложения рекордный счет загружается из файла, сохраняясь таким образом между различными сессиями игры

### Snake

**Snake** — классическая аркадная игра, где игрок управляет змейкой, собирая яблоки и избегая столкновений.

- **Поле игры**: 10×20 клеток (логическая сетка)
- **Управление**:
  - Стрелки ↑/↓/←/→ — движение змейки в соответствующем направлении
  - Space — старт/рестарт игры
  - P — пауза
  - Esc — выход
- **Цель игры**: набрать 200 очков, съедая яблоки и избегая столкновений
- **Механика**:
  - При съедании яблока змейка удлиняется, игрок получает очки
  - Столкновение со стенами или собственным телом завершает игру
  - Скорость игры увеличивается с повышением уровня
- **Система уровней**: скорость игры увеличивается по мере прогресса
- **Лучший результат (High Score)**: рекордный счет сохраняется в файл `snake_record_score.txt`. При достижении нового рекорда файл автоматически обновляется, сохраняя результат между сессиями игры

### Tetris

**Tetris** — культовая головоломка, где игроку необходимо собирать линии из падающих фигур (тетрамино).

- **Поле игры**: 10×20 клеток (логическая сетка)
- **Управление**:
  - Стрелки ←/→ — горизонтальное перемещение фигуры
  - Стрелка ↑ — поворот фигуры (вращение)
  - Стрелка ↓ — ускоренное падение фигуры
  - Space — старт/рестарт игры
  - P — пауза
  - Esc — выход
- **Цель игры**: заполнять горизонтальные линии, чтобы они исчезали и давали очки
- **Механика**:
  - На поле падают фигуры семи различных типов (I, J, L, O, S, T, Z)
  - При заполнении полной горизонтальной линии она удаляется, а блоки сверху опускаются
  - Очки начисляются за удаленные линии: 1 линия, 2 линии (больше очков), 3 линии, 4+ линии (максимум)
  - Игра завершается, когда новая фигура не может поместиться на поле
- **Система уровней**: каждые 600 очков = +1 уровень (максимум 10). С повышением уровня увеличивается скорость падения фигур
- **Лучший результат (High Score)**: рекордный счет сохраняется в файл `tetris_record_score.txt`. При достижении нового рекорда файл автоматически обновляется, сохраняя результат между сессиями игры

## Технологический стек

### Backend
- **Java 21** — основной язык разработки сервера
- **Spring Boot 3.4.3** — фреймворк для создания REST API
- **Spring Web** — веб-слой приложения
- **Spring Security** — безопасность (базовая конфигурация)
- **Lombok** — уменьшение boilerplate кода
- **Jackson** — JSON сериализация/десериализация

### Frontend
- **HTML5/CSS3/JavaScript** — веб-интерфейс
- **Qt Framework (C++)** — десктопное приложение
- **Java Swing** — альтернативный десктопный интерфейс
- **ncurses (C/C++)** — консольный интерфейс

### Интеграция
- **JNI (Java Native Interface)** — интеграция C/C++ кода для игр Snake и Tetris
- **libcurl (C++)** — HTTP клиент для REST API из C++ кода
- **RestAssured** — тестирование REST API

### Инструменты разработки
- **Gradle** — система сборки
- **JUnit 5 (Jupiter)** — тестирование Java кода
- **Google Test** — тестирование C++ кода
- **Swagger/OpenAPI** — документация API
- **Git** — система контроля версий

### Стиль кода
- **Google Java Style Guide** — стандарт форматирования Java кода
- **SOLID, KISS, DRY** — принципы проектирования
