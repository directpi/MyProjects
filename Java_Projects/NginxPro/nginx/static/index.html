🛍️ E-Commerce API

Веб-сервер и Reverse Proxy на базе Nginx

📡 Доступные Endpoints

  • /api/v1
    Swagger UI - документация API
  • /api/v1/health
    Проверка состояния сервиса
  • /admin
    pgAdmin - GUI для управления PostgreSQL
  • /status
    Статус Nginx сервера

🔧 Технические детали

  • Backend серверы: 3 инстанса (порты 8080, 8081, 8082)
    Балансировка нагрузки 2:1:1 для GET запросов
  • База данных: PostgreSQL (myshop_db)
    Read-only доступ для инстансов 8081 и 8082
  • Кеширование: Включено для статических файлов
    Исключение для API endpoints
  • Gzip сжатие: Включено
    Исключение медиа-типов (jpeg, png, gif, webp, video, audio)
